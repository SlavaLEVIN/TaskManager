# TaskManager

Программа для работы с задачами команды. Пользователи ведут свои задачи, администратор назначает исполнителей, управляет учётными записями и категориями. Данные хранятся в PostgreSQL.

## Скачать

Готовая программа находится в разделе [Релизы](https://github.com/SlavaLEVIN/TaskManager/releases). Скачайте `TaskManager.zip`, распакуйте и откройте `TaskManager.exe`. Для уже настроенной базы больше ничего запускать не нужно.

Архив исходников из меню **Code → Download ZIP** не содержит готовой программы.

В архиве программы есть два дополнительных мастера: `Создать базу.exe` для первой установки и `Обновить базу.exe` для обновления прав старой базы. Когда какой нужен, написано в `Инструкция.txt`.

## Исходный код

Код приложения — в `src/task_manager`, схема базы — в `database`, руководства и схемы — в `docs`. Скрипты для работы с базой лежат в `scripts`, настройки сборки — в `packaging`.

Для сборки нужны Python 3.13 x64 и зависимости из `packaging/requirements.txt`. В PowerShell из корня проекта запустите `scripts/build_windows.ps1`; готовые файлы появятся в `dist`.

Руководства: [пользователю](docs/user_manual.md), [системному программисту](docs/system_programmer_manual.md), [обновление](docs/UPDATE.md).
