# Миграции

Версия 1.0 использует исходную схему `../create_schema.sql`. Последующих миграций пока нет. Эта папка предназначена для будущих нумерованных SQL-изменений; клиент их автоматически не выполняет.

Перед изменением рабочей схемы: резервная копия → восстановление в отдельной БД → проверка миграции → согласованная остановка клиентов → применение на рабочей БД → проверка и обновление клиентов.
