# SQL и первичная настройка

`create_schema.sql` выполняется только в новой пустой базе. Он создаёт users, categories и tasks с ограничениями и индексами. Не удаляет существующие таблицы. `seed_categories.sql` отдельно заполняет справочник без демонстрационных пользователей и задач.

Для Windows рекомендуется `SETUP_DATABASE.cmd`: он создаёт БД, ограниченную техническую роль, схему, категории и первого прикладного администратора с заданным пользователем паролем. PostgreSQL должен быть установлен заранее.

Ручная настройка, LAN, привилегии, backup/restore: `docs/system_programmer_manual.md`. Демонстрационное наполнение: `scripts/seed_demo.py --confirm-demo`; нагрузка: `scripts/seed_load_test.py --confirm-demo`. Используйте отдельную пустую БД и явно заданный `--config`.

Тестовая БД должна оканчиваться на `_test`. Тесты очищают её таблицы; рабочую конфигурацию для тестов не используйте.
