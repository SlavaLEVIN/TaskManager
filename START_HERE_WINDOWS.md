# TaskManager для Windows

Распакуйте `TaskManager-Windows-Portable.zip` целиком в новую папку. Не запускайте EXE прямо из архива. Python устанавливать не нужно.

**База уже работает:** закройте старую программу и запустите новый `TaskManager.exe`. Настройки подключения остаются в `%LOCALAPPDATA%\TaskManager\database.ini`; задачи и пользователи остаются в PostgreSQL. Если вы сами хранили `database.ini` рядом со старым EXE, скопируйте этот файл рядом с новым EXE. Обновите ярлык, чтобы он указывал на новую папку. `SETUP_DATABASE.cmd` при обновлении не запускайте.

**Первая установка:** установите PostgreSQL 18, затем запустите `SETUP_DATABASE.cmd` на компьютере с сервером. Мастер создаст новую базу, техническую роль и администратора программы; запомните заданные пароли. После этого запускайте `TaskManager.exe` на каждом рабочем компьютере. На втором компьютере в настройках подключения укажите IP сервера, имя базы и технической роли.

**Права на категории:** если база создана старой версией, один раз запустите `UPDATE_DATABASE.cmd` для существующей базы. Потребуется пароль администратора PostgreSQL, обычно пользователя `postgres`. Мастер не пересоздаёт базу. Если право удаления категорий уже выдано через pgAdmin, повторный запуск не нужен.

В комплекте три программы: `TaskManager.exe` — приложение, `TaskManager-Setup.exe` — создание новой базы, `TaskManager-Update.exe` — обновление прав существующей базы. Файлы `.cmd` запускают соответствующие мастера и оставляют окно открытым, чтобы было видно результат. Подробные руководства находятся в репозитории на GitHub.
