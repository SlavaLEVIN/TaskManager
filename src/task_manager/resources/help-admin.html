Возможности администратора

Вам доступны задачи всех исполнителей. В разделе «Работа с задачами» можно создать, изменить и удалить задачу, назначить ответственного, указать категорию, срок и приоритет. При создании задача получает статус «Новая».

Учётные записи

В разделе «Управление пользователями» создаются учётные записи и назначаются роли. Кнопка «Сбросить пароль» задаёт новый пароль входа в программу. Чтобы удалить пользователя с задачами, сначала переназначьте их другому исполнителю. Последнего администратора удалить или перевести в пользователи нельзя.

Категории

Откройте «Категории задач» в меню. Можно добавить своё название или переименовать выбранную категорию. Переименование меняет подпись во всех связанных задачах. Например, для программных модулей и интерфейсов подойдёт «Разработка», для встреч и согласований — «Организация работы».

Экспорт и доступ к базе

В разделе отчётов доступны CSV-файлы задач и пользователей. Экспорт задач учитывает последние применённые условия раздела «Работа с задачами». Текстовый отчёт формируется отдельно по выбранным строкам на вкладке «Выбор задач».

Роль администратора приложения позволяет управлять задачами и пользователями. Права обслуживания PostgreSQL выдаются отдельно. Параметры подключения и режимы SSL описаны в «Инструкции для администратора» в окне настроек подключения.
