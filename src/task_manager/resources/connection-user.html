Подключение рабочего компьютера

Получите у администратора адрес сервера, порт, имя базы, технического пользователя PostgreSQL и его пароль. Перенесите значения в соответствующие поля. На другом компьютере адрес 127.0.0.1 не подойдёт: он указывает на сам компьютер. Укажите адрес общего сервера, который сообщил администратор.

Тайм-ауты и режим SSL оставьте согласованными с администратором. Сохраните настройки и нажмите «Повторить подключение» на экране входа. После успешной проверки войдите со своим логином TaskManager. Логин программы и технический пользователь PostgreSQL могут отличаться.
