Параметры подключения

Адрес сервера — имя или IP компьютера с общей базой. На самом сервере можно использовать 127.0.0.1; на рабочих компьютерах укажите его адрес в локальной сети. Порт — порт PostgreSQL, обычно 5432. Имя БД — существующая база TaskManager.

Технический пользователь PostgreSQL и пароль — учётные данные подключения клиента к базе. Используйте выделенную роль клиента, например task_client. Учётная запись postgres предназначена для обслуживания базы, а роль администратора TaskManager определяется после входа в приложение.

Тайм-аут подключения задаётся в секундах и ограничивает ожидание соединения. Тайм-аут запроса задаётся в миллисекундах и ограничивает выполнение отдельного запроса. Начальные значения — 5 секунд и 10000 миллисекунд. Увеличивайте их, если рабочая сеть или сервер требуют большего времени ответа.

Режимы SSL

disable — соединение без SSL. prefer — сначала попытка SSL, при невозможности допускается незашифрованное соединение. Этот режим не гарантирует шифрование.

require — требует SSL. Имя сервера не проверяется. При наличии файла доверенного корневого сертификата libpq также проверяет цепочку сертификата.

verify-ca — требует SSL и проверяет, что сертификат сервера подписан доверенным центром. verify-full — дополнительно сверяет адрес сервера с сертификатом. Для проверки нужен доверенный корневой сертификат: в Windows libpq читает его из %APPDATA%\postgresql\root.crt. Выбирайте режим, соответствующий настройкам сервера и выданным сертификатам.

Сохраните параметры и выполните проверку подключения. Подробности режимов приведены в документации PostgreSQL: https://www.postgresql.org/docs/18/libpq-ssl.html
