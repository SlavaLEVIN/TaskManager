Работа с задачами

Текущий логин и роль указаны вверху окна. Переходы между разделами, проверка подключения, настройки и выход из учётной записи находятся в меню справа.

Поиск и дедлайны

Введите часть названия или описания, выберите нужные условия и нажмите «Применить». Условия объединяются: задача должна соответствовать каждому из них. «Сбросить» возвращает полный доступный список.

Фильтр включается флажком «Дедлайн». Укажите даты «с» и «по»: обе входят в выбранный период. Проверяйте год: октябрь 2027 года не входит в неделю октября 2026 года. При снятом флажке даты не ограничивают список. Фильтры только скрывают строки и не удаляют задачи.

Статусы

Новая задача ещё не начата. Выделите её и нажмите «Взять в работу». Когда работа закончена, нажмите «Завершить задачу». Выполненную задачу можно вернуть в работу. Если работу над задачей пока отложили, её можно вернуть в новые.

«Просрочена» — условие отбора, а не отдельный этап работы. Оно действует для незавершённых задач с прошедшим дедлайном. Задача с дедлайном на сегодня ещё не просрочена. Выполненные задачи в этот отбор не попадают.

Приоритеты

Высокий — задачу стоит выполнить раньше остальных: она срочная или от неё зависит другая работа. Средний — обычный рабочий приоритет. Низкий — работу можно отложить, если появились более важные задачи. Приоритет не меняет дедлайн и статус автоматически. При одинаковом приоритете ориентируйтесь на дедлайн и договорённости с командой.

Отчёты

Откройте «Отчёты и экспорт», задайте условия и нажмите «Показать задачи». В один отчёт можно включить новые, выполняемые и выполненные задачи. Для выбора нескольких строк удерживайте Ctrl, для непрерывного диапазона — Shift. Кнопка «Выбрать все» отмечает весь показанный список.

«Текущая неделя» выбирает дедлайны с понедельника по воскресенье. Это отбор по дедлайну задачи, а не по дню её завершения: программа не хранит историю дат смены статуса. После выбора нажмите «Сформировать отчёт по выбранным задачам». На вкладке «Готовый отчёт» можно скопировать текст в документ. Дата создания относится к моменту формирования отчёта; при изменении задач сформируйте его заново.

Настройки и подключение

В настройках программы доступны светлая и тёмная темы, размер текста, начальный раздел и подтверждение закрытия. Эти параметры сохраняются отдельно на каждом компьютере.

Если операция завершилась ошибкой связи, выберите в меню «Проверить подключение». Успешный результат исчезает примерно через три секунды. Сообщение об ошибке показывается дольше; подробности можно прочитать в открывшемся окне. После восстановления связи обновите список. Если связь оборвалась при сохранении, сначала проверьте результат в списке, чтобы не создать повторную запись.
