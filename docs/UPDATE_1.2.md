# Обновление до 1.2.0

## Если TaskManager уже работает

1. Закройте TaskManager на обоих компьютерах.
2. Скачайте `TaskManager-Windows-Portable.zip` из релиза v1.2.0 и распакуйте целиком в новую папку. Старую папку пока сохраните. Обычные настройки подключения находятся в `%LOCALAPPDATA%\TaskManager\database.ini` и подхватятся автоматически. Если вы хранили `database.ini` рядом с EXE, скопируйте его в новую папку рядом с новым EXE.
3. На одном компьютере запустите **UPDATE_DATABASE.cmd** из нового архива. Это обновление существующей базы, а не её повторное создание. Мастер подставит сохранённый адрес, порт, имя базы и техническую роль: проверьте их. Введите имя и пароль администратора PostgreSQL (обычно `postgres`), затем подтвердите словом `UPDATE`. Пароль TaskManager здесь не подходит.
4. Обновление добавляет технической роли права создания и переименования категорий. Стандартная категория «Обслуживание» станет «Разработка», «Организационные» — «Организация работы». Если новое название уже занято, старая категория остаётся без изменений: её можно переименовать вручную. Идентификаторы категорий, задачи, пользователи и пароли сохраняются. Повторный запуск допустим.
5. На каждом рабочем компьютере запустите новый **TaskManager.exe** либо **START.cmd** из архива. Войдите со своим прежним логином и паролем. База обновляется один раз для всех клиентов.

**SETUP_DATABASE.cmd повторно запускать не нужно.** Он предназначен только для новой базы. PostgreSQL переустанавливать не нужно. Если обновление прав не выполнено, существующие задачи продолжат работать; при попытке изменить категорию программа покажет, какой мастер нужно запустить.

## Изменения

- Проверка подключения перенесена в меню. Результат показывается 2,8 секунды, ошибка — 9 секунд; подробности ошибки остаются в диалоге до закрытия.
- На экране входа удалена подпись о доступных действиях. Для EXE добавлена собственная многоразмерная иконка, значок меню заменён на SVG с равными интервалами.
- В таблицах расширяется название задачи, а не колонка просрочки. В текстовом отчёте просрочка отмечается только при её наличии; дата подписана «Дата создания отчёта». Сохранение TXT удалено, копирование текста и CSV остаются.
- Администратор может создавать и переименовывать категории через меню «Категории задач».
- Общая справка дополнена приоритетами и разделами для текущей роли; установка вынесена в документацию. Абзацы выровнены по ширине.
- В настройках подключения открываются отдельные инструкции для пользователя и администратора, включая SSL. У порта и тайм-аутов убраны кнопки изменения значения, у размера текста исправлены стрелки.
- Неактивные поля периода затемнены и недоступны для ввода. В отчётах показан применённый период и число найденных задач. Границы периода включены. Задача со сроком в 2027 году правильно исключается из периода 2026 года.

Описание SSL сверено с [документацией PostgreSQL 18](https://www.postgresql.org/docs/18/libpq-ssl.html).
