# Технические решения реализации

Источник требований — предоставленный MasterPrompt; пользователь подтвердил реализацию полностью по нему. Отдельное ТЗ не получено. Перечисленное ниже — уточнения реализации, не дословная цитата утверждённого ТЗ.

| № из раздела 22 | Принятое решение |
|---|---|
| 1 | MVP: представления → Presenter → сервисы → Database |
| 2 | assignee_id и category_id — FK на единственного исполнителя и категорию |
| 3 | Database — провайдер отдельных соединений и транзакций на операцию |
| 4 | ADMIN меняет статус с теми же ограничениями, включая форму редактирования |
| 5 | Смысловой порядок приоритетов/статусов, дополнительная сортировка по ID |
| 6 | Период включителен; одинаковые границы означают одну дату; обратный диапазон отклоняется |
| 7 | CURRENT_DATE сервера; при новой установке timezone Europe/Moscow |
| 8 | CSV задач использует текущий загруженный отбор; пользователей — весь безопасный список |
| 9 | trim внешних пробелов логина, lower(login) при входе/уникальности; пароль не нормализуется |
| 10 | Сведения в нижней панели списка задач |
| 11 | Начальные категории — изменяемое системным администратором наполнение БД, без GUI |
| 12 | Бизнес-лимиты длины текста не введены; QLineEdit расширен до технического int-лимита; bcrypt >72 байт отклоняется явно |
| 13 | Последний ADMIN защищён атомарно общей транзакционной advisory-блокировкой операций с пользователями |
| 14 | Session хранит ID; сервис каждый раз читает роль; удаление прекращает доступ, переименование сохраняет назначения |

Дополнительно:

- Qt Widgets поставляются официальным `PySide6-Essentials`; Addons не используются.
- CSV содержит BOM для удобного открытия кириллицы в Excel. Это UTF-8. Формулы не преобразуются: требование сохранить исходный текст соблюдено; при импорте пользователь может выбрать тип колонок «Текст».
- Ошибки интерфейса не уничтожают введённые данные формы; успешная запись закрывает форму и обновляет список.
- При смене роли между началом/концом операции Presenter отбрасывает показ результата и очищает данные. Уже совершённая в разрешённый момент запись не откатывается задним числом.
- Фоновая очередь одного клиента последовательна; каждый вызов сервиса получает своё соединение.
- У обычных текстовых полей задачи нет optimistic locking. Последнее сохранение побеждает. Статус проверяется в транзакции относительно актуальной заблокированной строки.
- Переносимый Windows-комплект добавлен для запуска без установленного Python. Он не объявляется выполненной проверкой единого EXE. Сценарий PyInstaller и workflow находятся в поставке; в версии 1.1 Windows-сборка и краткая проверка старта выполнены в GitHub Actions; полное испытание на физических ПК остаётся отдельным этапом.
- Конфигурация с техническим паролем хранится на рабочей станции. Мастер не сохраняет пароль PostgreSQL-superuser и пароль администратора приложения в файлы.
