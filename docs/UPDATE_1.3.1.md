# Обновление TaskManager до 1.3.1

1. Закройте TaskManager на обоих компьютерах. Скачайте `TaskManager-Windows-Portable.zip` из релиза v1.3.1 и распакуйте весь архив в новую папку на каждом ПК.
2. На компьютере с доступом к PostgreSQL один раз запустите **UPDATE_DATABASE.cmd** из нового архива. Укажите существующую базу и техническую роль, затем пароль администратора PostgreSQL. Мастер выдаст роли право удалять категории. Задачи, пользователи и настройки подключения сохранятся. Базу пересоздавать не нужно.
3. На обоих ПК запустите новый **TaskManager.exe** или **START.cmd** из новой папки. Проверьте, что в разделе «Категории задач» появилась кнопка «Удалить», а в «Работа с задачами» осталась одна кнопка применения фильтров.
4. Обновите ярлыки, чтобы они указывали на новую папку. После проверки старую папку можно удалить.

Категория удаляется только тогда, когда с ней не связана ни одна задача. Для удаления сначала перенесите её задачи в другие категории. Если обновление базы пока не выполнено, остальная работа приложения сохранится, а при удалении категории появится сообщение о необходимости запустить мастер.
