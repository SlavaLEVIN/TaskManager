# Правила предметной области

1. Две роли: USER и ADMIN. Системный администратор PostgreSQL не является третьей ролью приложения.
2. Пользователь видит и изменяет статус только собственных назначенных задач. Администратор управляет всеми задачами и учётными записями.
3. Логин обязателен; внешние пробелы удаляются. Сравнение без учёта регистра обеспечивает `lower(login)` в PostgreSQL. Пароль обязателен, не обрезается и не нормализуется; ограничение bcrypt — 72 байта UTF-8.
4. Каждая задача имеет существующих ответственного и категорию, непустое название, приоритет и дату. Описание может быть пустым. Новый статус всегда NEW.
5. NEW → IN_PROGRESS; IN_PROGRESS → NEW / COMPLETED; COMPLETED → IN_PROGRESS. Повтор того же статуса — отсутствие изменения. Единственный источник таблицы переходов — `TRANSITIONS` в `domain.py`.
6. Просрочена тогда и только тогда, когда `due_date < CURRENT_DATE` и статус не COMPLETED. Сегодня не просрочено. Просрочка не хранится отдельным столбцом.
7. Создание с прошедшей датой разрешено. Дата без времени. Серверная часовая зона при первоначальной настройке — Europe/Moscow.
8. Поиск по названию или описанию без учёта регистра; `%`, `_`, кавычки — обычные символы. Все фильтры соединены AND, границы периода включены.
9. Порядок приоритетов LOW, MEDIUM, HIGH; статусов NEW, IN_PROGRESS, COMPLETED. При равенстве ключа используется ID в том же направлении.
10. Удалить пользователя с задачами нельзя. Сначала переназначить все задачи. Последнего администратора удалить или понизить нельзя.
11. Изменение логина/роли сохраняет ID, хеш пароля и назначения. Сброс пароля — отдельная операция. Изменение роли учитывается при следующем защищённом запросе.
12. Отчёт строится по повторно прочитанным ID, доступным текущему пользователю. Пустой выбор отклоняется. История, дата фактического завершения и трудозатраты не придумываются.
13. CSV задач соответствует условиям последнего успешно загруженного списка; CSV пользователей включает только ID, логин, роль. Формат UTF-8 с BOM, `;`. Исходный текст не изменяется.
14. Отмена формы и выбора файла не записывает данных. Удаление подтверждается. Logout очищает таблицы, выбор, отчёт и сессию. Отмена выхода сохраняет текущий экран и несохранённый ввод.
