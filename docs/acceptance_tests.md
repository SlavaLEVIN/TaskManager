# Ручная приёмка TaskManager

Проверяйте программу на отдельной базе и двух компьютерах Windows. Перед испытанием запишите дату, версии Windows и PostgreSQL, адрес сервера и версию TaskManager. Для каждого пункта отметьте результат и приложите скриншот или краткую запись о дефекте. Рабочую базу не очищайте.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Войти администратором и пользователем; попробовать неверный пароль | Верный вход успешен, неверный отклонён |
| 2 | Сравнить меню двух ролей | Пользователь не видит управление пользователями и категориями |
| 3 | Создать задачи двум исполнителям | Пользователь видит только свои задачи; администратор — все |
| 4 | Найти задачу по названию и описанию, с кириллицей и разным регистром | Поиск возвращает нужные строки |
| 5 | Совместить статус, приоритет, категорию, исполнителя и диапазон дат | Все условия действуют одновременно; границы дат включены |
| 6 | Отсортировать задачи по каждому доступному полю в обоих направлениях | Порядок соответствует выбранному полю и направлению |
| 7 | Перевести задачу «Новая → В работе → Выполнена», затем вернуть в работу | Разрешённые переходы работают; запрещённые не предлагаются |
| 8 | Создать задачу с пустым названием, затем с заполненными полями | Пустое название отклонено; корректная задача сохранена |
| 9 | Редактировать название и описание дольше 10 секунд | Поля не теряют фокус и введённый текст |
| 10 | Изменить исполнителя задачи с другого клиента и нажать «Применить» | Список перечитан; права доступа обновились |
| 11 | Начать удаление задачи и отменить, затем подтвердить | После отмены задача остаётся; после подтверждения удаляется |
| 12 | Создать пользователя, сменить логин и роль; попробовать дубликат логина | Изменения сохраняются, дубликат отклонён |
| 13 | Попробовать удалить пользователя с задачами; переназначить задачи и повторить | Сначала отказ, после переназначения удаление возможно |
| 14 | Сбросить пароль пользователя при открытой сессии | Старый пароль не работает; сессия завершается при проверке |
| 15 | Добавить, переименовать и удалить пустую категорию | Изменения видны в списке и задачах |
| 16 | Попробовать удалить категорию с задачей | Удаление отклонено; задача сохранена |
| 17 | Выбрать задачи разных статусов и сформировать отчёт | В отчёт попадают выбранные задачи и текущие статусы |
| 18 | Экспортировать CSV с кириллицей, кавычками и переносом строки | Файл открывается без потери текста и столбцов |
| 19 | Остановить тестовый PostgreSQL, затем запустить его снова | Приложение остаётся открытым; повторное подключение показывает результат |
| 20 | Изменить одну задачу с двух компьютеров | Второй клиент видит сохранённое изменение после «Применить» |
| 21 | Создать в тестовой базе 100 пользователей и 1000 задач | Список и фильтры работают; измерить время и память клиента |
| 22 | Запустить архив на Windows без Python, отключив Интернет при доступной LAN | Приложение и локальная справка работают |
| 23 | Проверить отмену формы, выход из учётной записи и закрытие программы | Несохранённые данные не записываются; выход очищает личные данные |

После каждого испытания, меняющего базу, проверяйте состояние в интерфейсе или pgAdmin. Для испытания резервного копирования восстановите дамп **в отдельную базу** и сравните количество пользователей, категорий и задач. Не восстанавливайте дамп поверх рабочей базы.
