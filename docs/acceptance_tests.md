## Проверка Windows после распаковки / сборки EXE

1. На ПК без установленного Python распаковать комплект. Запустить `START.cmd`; для onefile-поставки — `TaskManager.exe`.
2. Настроить БД на одном ПК; на втором задать IP сервера. Отключить Интернет, сохранив LAN.
3. Войти администратором, создать пользователя и задачу; на втором ПК войти исполнителем, увидеть только свою задачу.
4. Выполнить изменение статуса, переназначение, обновление, отчёт, CSV с кириллицей и переносом строк.
5. Проверить масштаб Windows 100%, 125%, 150%, ширину окна 1000 px и изменение размеров. Не должно быть перекрывающихся полей; таблица может прокручиваться.
6. Открыть справку при отключённом Интернете. Вернуться в прежний раздел.
7. Отменить создание/редактирование/удаление/выбор CSV; убедиться, что данные/файлы не созданы. Отменить выход с несохранённой формой; ввод должен сохраниться.
8. Во время работы отозвать ADMIN через другой клиент. Следующее защищённое действие должно очистить прежние данные и обновить меню.
9. Остановить только тестовую PostgreSQL. Убедиться, что клиент не падает, ошибка не выглядит успехом. Запустить сервер, нажать повторное подключение; измерить время от команды до готовности (≤1 мин).
10. Для EXE измерить суммарную память процессов bootloader и дочернего клиента в Диспетчере задач/Process Explorer. Сравнить с 300 МБ. Записать холодный запуск отдельно от операций уже работающего клиента.

## Замеры

`benchmark.py` вызывает действия Presenter и ждёт завершения фоновой операции и обновления модели/виджетов. В режиме offscreen это не измерение вывода пикселей на физический экран. Для целевой приёмки запустите без `QT_QPA_PLATFORM=offscreen`, проверьте видимое отображение и сохраните условия среды.

Нагрузка: 100 записей users, 4 categories, 1000 tasks; название примерно 60 символов, описание до 90 символов, 25% пустых описаний, смешанные приоритеты/статусы/даты. Отчёт и CSV — по всем 1000 задачам. Не считать размер SQL-файла размером БД.

Неизвестный исход commit при физическом разрыве ровно во время подтверждения предусмотрен кодом, но отдельное воспроизводимое сетевое испытание этого момента не выполнено. Не считать тест rollback доказательством проверки этого частного случая.
