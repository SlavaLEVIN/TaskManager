# Обновление TaskManager до 1.3.0

1. Закройте программу на обоих компьютерах. Скачайте `TaskManager-Windows-Portable.zip` из релиза v1.3.0 и распакуйте его в новую папку на каждом ПК. Старую папку пока сохраните.
2. Запустите новый `TaskManager.exe` на обоих ПК. Войдите с прежними логинами и паролями. Настройки подключения в `%LOCALAPPDATA%\TaskManager\database.ini` сохраняются между версиями.
3. Проверьте в меню администратора раздел «Категории задач»: кнопки «Добавить» и «Переименовать» расположены под списком. Для переименования выделите строку. Если появится сообщение о нехватке прав технической роли, один раз запустите `UPDATE_DATABASE.cmd` на компьютере с PostgreSQL, указав существующую базу и учётную запись администратора PostgreSQL. Это обновление описано в [инструкции к 1.2.0](UPDATE_1.2.md). Повторно создавать базу не нужно.
4. Обновите ярлыки на обоих ПК, чтобы они запускали новый EXE. После проверки старую папку можно удалить.

Изменены подписи и расположение колонок, редактор дедлайна и справка. После сброса пароля администратором открытая сессия пользователя завершится при очередной проверке — обычно в течение 10 секунд при доступной базе. Для этого новая версия должна быть запущена на обоих компьютерах. Структура базы для отзыва сессий не меняется.
