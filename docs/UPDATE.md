# Обновление существующей установки

1. Закройте TaskManager на всех рабочих компьютерах.
2. Скачайте `TaskManager.zip` из последнего релиза и распакуйте его в новую папку на каждом ПК.
3. Запустите новый `TaskManager.exe` прямо из этой папки. Проверьте вход и список задач, затем замените старые ярлыки. Старую папку удаляйте после проверки.

Задачи и пользователи хранятся в PostgreSQL. Настройки подключения обычно хранятся в `%LOCALAPPDATA%\TaskManager\database.ini` и подхватываются автоматически. Если старый `database.ini` лежал рядом с EXE, перенесите его в новую папку рядом с новым EXE.

`Создать базу.exe` предназначен **только для новой базы**. Если приложение сообщает о нехватке прав на категории, запустите `Обновить базу.exe` один раз для существующей базы. Укажите её имя, техническую роль и пароль администратора PostgreSQL. Пересоздавать базу не нужно. Если нужные права уже выданы через pgAdmin, мастер обновления не требуется.
