# Обновление TaskManager 1.1

## Как обновить уже настроенную программу

1. Закройте TaskManager на компьютере.
2. Скачайте `TaskManager-Windows-Portable.zip` из релиза **v1.1.0**.
3. Распакуйте архив целиком в новую папку, например `C:\TaskManager-1.1`.
4. Запустите `START.cmd` из новой папки.
5. Войдите под прежним логином. На том же Windows-пользователе программа прочитает прежний `%LOCALAPPDATA%\TaskManager\database.ini`.
6. Нажмите проверку подключения. Сверху должен появиться положительный результат.

**SETUP_DATABASE.cmd повторно не запускайте.** Схема базы в этой версии не меняется. Задачи, пользователи, пароли и категории хранятся в PostgreSQL. При настройке через TASK_MANAGER_CONFIG или использовании database.ini рядом со старым EXE сохраните этот собственный путь/файл.

Обновите программу на обоих ПК. PostgreSQL переустанавливать не нужно. Старую папку можно сохранить до проверки новой версии.

Также устранена ошибка 42501 при создании/редактировании задач технической ролью: проверка категории больше не запрашивает ненужную блокировку. Ссылочную целостность сохраняет внешний ключ PostgreSQL. Права категории остаются только на чтение.

## Статусы и недельный обзор

Завершение доступно после начала работы: «Новая → В работе → Выполнена». Для новой задачи интерфейс явно объясняет этот порядок.

В отчёт можно включить любые доступные задачи с разными статусами. «Текущая неделя» отбирает **по сроку задачи**. Истории переходов и даты фактического завершения в существующей базе нет, поэтому отчёт не выдаёт срок за дату завершения. Для свободного недельного обзора снимите фильтр периода и выберите нужные выполненные и текущие задачи.
